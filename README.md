# Timezone

A macOS menu bar app for people who work across time zones. Click the clock in the menu bar (or press the global hotkey) and a popover shows everyone you care about on a shared 24-hour timeline.

## Features

- Add people by city; the time zone is resolved offline from a bundled dataset (IANA zones + major cities).
- Photo or initials avatars, groups (Team, Clients, Family…) to filter the timeline.
- One 24-hour row per person with working hours, off-hours and night shaded differently.
- Draggable time cursor across every row, a **Now** button, previous/next day arrows, ←/→ nudges by 15 minutes.
- Copy all times in one click, as a one-line Slack message or a multi-line email, with a *next day* tag where the date changes.
- Public holidays per country from an offline rule set, custom weekend days per person (e.g. Fri + Sat).
- Daylight-saving warnings a week before someone's clocks change.
- **Best time**: select people (click their avatar) and the top 3 slots inside everyone's working hours are highlighted.
- Menu bar can show an icon or someone's live time. Global hotkey, launch at login, light/dark mode, 12/24-hour clock.

## Stack

Tauri 2 + React 19. Deliberately few dependencies:

- Rust: `tauri` (tray icon), `tauri-plugin-global-shortcut`, `tauri-plugin-autostart`, `serde`.
- Frontend: `react`, `react-dom`, `@tauri-apps/api`. No UI, date or icon libraries; everything is `Intl` and plain CSS.
- Clipboard goes through `pbcopy`; persistence is a JSON file in the app data directory.

## Layout

```
src-tauri/src/lib.rs      native shell: tray, popover placement, commands
src/app.tsx               state wiring and views (timeline / editor / settings)
src/components/           SearchBar, DayHeader, Timeline, BestTimes, CopyBar, PersonEditor, SettingsPanel
src/lib/time.ts           Intl-based timezone math (offsets, day bounds, DST detection)
src/lib/holidays.ts       offline holiday rules (fixed, nth-weekday, Easter-relative, observed days)
src/lib/schedule.ts       day phases per person and the best-slot search
src/lib/clipboard.ts      Slack / email formatting
src/data/cities.json      generated by scripts/build-cities.ts
```

## Develop

```sh
bun install
bun tauri dev        # native app
bun run dev          # UI only in a browser (state kept in localStorage)
bun run cities       # regenerate src/data/cities.json from the system zone table
bun tauri build      # .app / .dmg
```

Lunar and Islamic holidays (Eid, Diwali, Lunar New Year…) move every year and are not included in the offline rule set.
